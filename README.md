# 利润中枢 · 电商财务分析平台 1.0

本版本包含：CSV/XLSX 利润表导入、字段自动识别、收入/毛利/费用/净利润卡片、平台利润贡献图、利润明细表、当前视图导出、手机端响应式查看。

## 启动

```powershell
cd D:\Backup\Documents\自动化\ecommerce_finance_platform
python server.py
```

打开 http://127.0.0.1:18780 。健康检查：http://127.0.0.1:18780/api/health

## 导入列名

至少需要一列收入字段（收入、销售额、营业收入、销售收入、成交金额、买家应付货款之一）；平台、店铺、成本、费用、利润列会自动匹配，缺失利润列时按收入-成本-费用计算。

## 1.1 预留

前端使用结构化 `summary / by_platform / rows` 数据；后续可在服务端增加 `/api/analysis`，把分析建议作为独立模块接入，不改变 1.0 的财务计算和表格展示合同。
